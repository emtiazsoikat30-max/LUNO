# Bangladesh address reference data

`bangladesh-districts.source.json` and `bangladesh-upazilas.source.json` are the offline reference data used by the LUNO delivery form. They contain 64 districts and 495 upazilas with English and Bangla names.

Source: [open-admin-data/bangladesh-administrative-divisions](https://github.com/open-admin-data/bangladesh-administrative-divisions), CC-BY-4.0. Update both source files together when the upstream administrative dataset changes.
